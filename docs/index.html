Keep the project moving beyond a single chat.

When work spans many conversations, files, and versions, it becomes harder to see what is current and where to resume. TaskCarry keeps the connected tasks, saved work, decisions, and deliverables in persistent local records.

01

Project memory

Keep task progress, important decisions, and next steps outside a temporary chat context.

02

Independent collaboration

Let professional chats work in separate workspaces, then bring their completed stages together.

03

Work you can continue

Save selected work, retain version history, and check what happened before resuming supported operations.

Bring the work you already have.

Connect an existing chat with a summary of its tasks, deliverables, and unfinished work. Keep a suitable original workspace, and add independent workspaces when parallel responsibilities need them.

Experience that helps the next action.

For supported known problems, the toolkit checks applicable recovery rules and actual effects before completing missing steps. New problems still need diagnosis; saving a note alone does not add a new executable repair.

Start with one project.

  1. Install TaskCarry and connect one project using the operating manual.
  2. Start your first governance chat with the project name and a one-sentence introduction. Review its initial feedback and next steps.
  3. Add professional workspaces and optional scheduling in your AI host when needed.

Operating manualProduct introduction

Codex provides the AI; TaskCarry provides local records and checked tools. Python 3.11+ is required; Git is needed for workspace collaboration. Optional scheduling is configured in the host. Multi-computer guidance is documented but has not completed a real two-computer end-to-end validation.

从一个真实项目开始。

  1. 按操作手册安装 TaskCarry，接入一个项目。
  2. 开始首次治理聊天，提供项目名称与一句话介绍，查看首次反馈与下一步。
  3. 根据需要接入专业工作台，并在 AI 宿主中配置可选的定时任务。

工作繼續，專案記憶也繼續。

當工作跨越許多對話、檔案與版本，目前進展和接續位置會越來越難整理。TaskCarry 將已接入的任務、已保存的工作、重要決定與階段成果，保存在持久的本機專案記錄中。

01

長期專案記憶

讓任務進度、重要決定與下一步保存在對話暫時的上下文之外。

02

獨立工作台協作

專業對話在各自工作區推進，再把完成的階段成果匯入專案。

03

隨時找到接續位置

保留選定工作與版本歷史，先核對已經發生的操作，再繼續支援的後續步驟。

帶著原來的工作接入。

整理原對話的任務、成果與未完成工作，即可依手冊完成接入。合適的原工作區可以繼續使用，需要並行的職責再安排獨立工作區。

讓經驗幫助下一次行動。

針對已支援的已知問題，工具先核對適用經驗與實際效果，再補上缺失的步驟。新問題仍須診斷；寫下一條經驗本身，不會自動產生新的修復功能。

從一個真實專案開始。

  1. 依操作手冊安裝 TaskCarry，接入一個專案。
  2. 開始首次治理對話，提供專案名稱與一句話介紹，查看首次回饋與下一步。
  3. 依需要接入專業工作台，並在 AI 宿主中設定可選的定時任務。

操作手冊產品介紹

Codex 提供 AI，TaskCarry 提供本機記錄與受檢查的工具。需要 Python 3.11+；工作區協作功能還需 Git。可選定時任務在宿主中設定。多電腦建議流程已寫入手冊，尚未完成真實雙電腦端到端驗證。
