Keep the project moving beyond a single chat.

When work spans many conversations, files, and versions, it becomes harder to see what is current and where to resume. TaskCarry keeps the connected tasks, saved work, decisions, and deliverables in persistent local records.

01

Remember the project

Keep task progress, important decisions, saved checkpoints, and next steps beyond a single chat.

02

Coordinate deliverables

Work in independent workspaces, connect stages to their tasks, and bring ready results into a shared project with clear version relationships.

03

Govern project workflows

Review stage plans, check workspace state, preserve supported unfinished work, and resume interrupted operations from verified effects.

TaskCarry connects people, AI, and local records

You decide project direction and final acceptance. The governance AI in your host interprets the connected work and reviews the next action; TaskCarry retains project state and performs checked operations. This governs how project work is received and continued. Your AI host provides its own identity, permissions, and security controls.

Start with one project.

  1. Install TaskCarry and connect one project using the operating manual.
  2. Start your first governance chat with the project name and a one-sentence introduction. Review its initial feedback and next steps.
  3. Add professional workspaces and optional scheduling in your AI host when needed.

Operating manualProduct introduction

Your chosen host provides the AI; TaskCarry provides local records and checked tools. The current step-by-step guide uses Codex; other hosts need their own connection and workflow verification. Python 3.11+ is required; Git is needed for workspace collaboration. Optional scheduling is configured in the host. Multi-computer guidance is documented but has not completed a real two-computer end-to-end validation.

当工作跨越许多对话、文件与版本，当前进展和接续位置会越来越难整理。TaskCarry 将已接入的任务、已保存的工作、重要决定与阶段成果，保存在持久的本地项目记录中。

工作繼續，專案記憶也繼續。

當工作跨越許多對話、檔案與版本，目前進展和接續位置會越來越難整理。TaskCarry 將已接入的任務、已保存的工作、重要決定與階段成果，保存在持久的本機專案記錄中。

01

記住專案

在單一對話之外，保留任務進度、重要決定、已儲存的檢查點與下一步。

02

協調成果

各自在獨立工作區推進，將階段成果關聯至任務，核對版本關係，再把準備好的成果匯入共同專案。

03

治理推進過程

審閱階段接收計畫，核對工作區狀態，保全支援範圍內的未完成工作，並依據實際效果接續中斷的操作。

TaskCarry 連結人、AI 與本機專案記錄

你決定專案方向與最終驗收。宿主中的治理 AI 理解已接入的工作並複核下一步；TaskCarry 保存專案狀態，執行經過校驗的操作。這套治理圍繞專案成果如何接收與繼續推進展開；身分、權限與安全控制由 AI 宿主自身提供。

操作手冊產品介紹

你選擇的宿主提供 AI，TaskCarry 提供本機記錄與經過校驗的工具。目前逐步說明使用 Codex；其他宿主須分別核驗連線與工作流程。需要 Python 3.11+；工作區協作功能還需 Git。可選定時任務在宿主中設定。多電腦建議流程已寫入手冊，尚未完成真實雙電腦端到端驗證。
