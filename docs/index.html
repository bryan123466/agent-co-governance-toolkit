Operating manualProduct introduction

Codex provides the AI; AGCT provides local records and checked tools. Python 3.11+ and Git are required. Optional scheduling is configured in the host. Multi-computer guidance is documented but has not completed a real two-computer end-to-end validation.

A self-contained overview. Diagrams are bundled; there are no remote fonts, tracking, or external scripts.
