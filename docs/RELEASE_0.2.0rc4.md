# TaskCarry 0.2.0rc4

[English](#english) · [简体中文](#简体中文) · [繁體中文](#繁體中文)

## English

TaskCarry brings project memory and workspace collaboration to local AI tools. Keep task progress, saved checkpoints and delivered stages together, then let the governance chat use those records to coordinate work and continue supported interrupted operations.

This release unifies the product, Python package, `taskcarry` command, MCP tools, four Skills and `.taskcarry` project state under one name. The English, Simplified Chinese and Traditional Chinese walkthroughs use the same TaskCarry directory examples. Install the packaged wheel from this release; a package-registry publication is not implied.

Start in your governance chat, connect the workspaces you choose, and request one initial governance run. Its result shows what was actually connected and processed. The optional recurring task uses the same workflow and reports meaningful changes in that chat. No separate reporting service or dashboard is required. An empty new project can be ready for work without inventing a delivery.

The engine retains precise Git stage reception, checkpoint restoration, workspace work preservation, bounded receiving plans and evidence-based continuation. CLI and MCP share the same implementation. Codex examples are included; the CLI and MCP interfaces provide integration points for other local AI tools. Native client loading, scheduled triggers and physical multi-computer operation must be verified in their actual environments.

## 简体中文

TaskCarry 为本地 AI 工具提供项目记忆与工作区协作。任务进度、检查点和已交付的阶段成果保存为可查询的记录，由治理聊天据此整理工作，并接续已支持的中断操作。

本版统一产品名称、Python 包、`taskcarry` 命令、MCP 工具、四个 Skills 和 `.taskcarry` 项目状态。英文、简体、繁体操作手册使用同一套 TaskCarry 目录示例。请安装本次 Release 附带的 wheel；这不表示已经发布到包管理平台。

安装后在治理聊天接入需要的工作区，直接要求执行一次首次治理，查看真实连接与处理结果。可选定时任务复用相同流程，在当前聊天说明有意义的变化；无需另外安装报告服务或看板。空白新项目可以直接进入可工作状态，不必虚构交付。

现有内核继续提供精确阶段接收、检查点恢复、工作区未完成工作保全、有限接收计划和依据实际效果的接续。CLI 与 MCP 共用实现。包内提供 Codex 操作示例，其他本地 AI 工具可通过 CLI/MCP 适配；实际客户端加载、定时触发和实体多电脑运行分别以现场验证为准。
