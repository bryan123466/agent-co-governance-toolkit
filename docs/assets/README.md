# Public illustration assets / 公開圖示素材

The collaboration SVG files show how project owners, a governance chat, professional workspaces, and persistent project records work together. The governance-flow SVG files show how daily work is saved, brought into the project, and continued. Both sets are available in English, Simplified Chinese, and Traditional Chinese and are maintained as editable vector diagrams.

`workspace-sidebar-example.png` is an AI-assisted illustrative redraw of a dark workspace sidebar. It uses generic role names and is not a capture of an installed toolkit or evidence of completed automation. The original project-specific screenshot is not distributed. The workspace count, role assignments, and separation of project management from governance are examples, not installation requirements. Additional backup or observer chats are optional organizational choices and are not required by this toolkit.

The PNG is visually reviewed and included by exact path and SHA-256 in the release builder. A changed image requires a new review; arbitrary screenshots and binary files are not automatically packaged.

協作 SVG 說明專案負責人、治理對話、專業工作區與持久專案記錄的分工；治理流程 SVG 說明日常工作如何保存、匯入專案與接續。兩組圖示皆提供英文、簡體中文與繁體中文版本，並以可編輯向量圖維護。

側欄 PNG 是使用通用角色名稱製作的 AI 輔助示意重繪，不是工具安裝實況或自動化完成證據；不發布原專案的實際截圖。工作區數量、職責及專案管理與治理是否分開，皆可按需要安排；備用或觀察對話不是必要設定。

## Repository social preview / 仓库分享图 / 儲存庫分享圖

`social-preview.svg` is the editable source for the TaskCarry repository sharing image. `social-preview.png` is its 1280 × 640 rendered export. The composition was authored as vector text, shapes, and connectors: three independent workspaces connect to local project memory, with the product name and the promises “Remember progress / Coordinate workspaces / Resume work.” This is an original public product diagram, not a product screenshot or a record of installed automation. The SVG uses local system fonts; no remote fonts or external resources are required.
