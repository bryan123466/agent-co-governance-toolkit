# 讓定時治理保持聚焦

[English](../en/automation.md) · [简体中文](../zh-CN/automation.md)

先在專案治理對話中設定一個定時任務，重用手動治理所用的 AGCT 工具與 control 目錄。AI 負責理解任務證據，工具負責精確計畫、執行與記錄本機操作。安裝 AGCT 本身不會建立排程器，也不會再啟動另一套 AI 服務。

## 從最小設定開始

| 任務 | 職責 | 起步建議 |
|---|---|---|
| 治理任務 | 接收明確交付，接續未完操作，說明目前進度與具體下一條件 | 每日兩次，例如專案所選時區的 09:00、17:00 |
| 可選唯讀觀察 | 核對目前記錄與執行環境，發現新增故障、結果不一致或證據缺口 | 每日一次，安排在治理時段之後 |
| 獨立採集任務 | 起步通常不需要，治理已經讀取登記工作 | 有獨立來源與實際需要時再增加 |

時段是範例，不是固定要求。一份 control 及其接收基線由一個治理寫入者負責；觀察者不寫入，也不成為額外批准層。專業視窗繼續獨立工作，錯過時段後不需要重播每一個完整舊週期。

## 在既有治理對話中直接使用

先讓治理依下方執行說明手動執行一輪，檢查實際效果、處理範圍與剩餘項。確認符合預期後，使用這段設定提示詞：

> 請為本對話已接入的專案建立持續回到本對話的定時治理任務，每天 09:00 和 17:00 執行，顯示實際採用的時區與儲存後的計畫。保持目前模型與權限。每輪使用下方執行說明，每天第一輪同時提供晨報。沒有有意義變化、失敗或需要我操作的事項時保持安靜。不另建 control，不為其他專案啟用自動化。

將以下內容儲存為定時任務的執行說明：

```text
繼續治理本對話已明確接入的專案，使用已安裝的 AGCT 工具與原 control 目錄。依 $agct-governance-reconcile 工作，具體失敗依 $agct-experience-recovery 判斷。專案方向與專業驗收仍由原責任人決定。

先讀 agenda 和必要的 status 細節。詢問前重用已有任務、檢查點、交付、材料與使用者決定證據。若獲准的宿主工具能讀取已接入對話，只查看發生變化或存在具體缺口的必要資訊；無法讀取時說明涵蓋範圍，繼續有記錄支持的工作。不從檔案變化直接推定已交付，不讀無關對話。

選擇小批接收範圍，通常使用 reconcile limit 20，並核對實際凍結計畫。agenda 的一頁不是執行範圍。接續前先核對已發生的效果，在已有授權內執行精確計畫，保留未完操作與檢查點。只有專業任務確實需要程式碼或成果依賴時才用 adopt 更新工作區；讀取公共進度或更新 Skills 不要求合併業務分支。

依錯誤碼、範圍與目前證據判斷經驗是否適用。refresh_plan 只建議產生新計畫。輸入未變的衝突要解決具體條件，不循環重試。在獲准開發範圍內修改共用實作，將候選與已安裝執行版分開驗證；暫不可執行時保留具名下一條件。不巢狀啟動完整治理，不靠修改宿主權限、帳號或排程修復單項任務。

分別說明本計畫結果與目前全部剩餘事項，批次完成不代表專案完成。暫停任務與已確認保留決定不反覆催辦。在安全位置儲存精確操作與下一步，結束前核對一次實際回執，不為了出報告重新全查歷史。只對有意義變化、失敗或需要使用者操作的事項通知；每天第一輪另附簡明晨報。
```

Skills 使用正常安裝位置；定時任務中應儲存上述說明，不能只依賴先前一則臨時對話。透過宿主提供的排程工具建立，並檢查實際儲存定義；不手改原生排程檔案，不將憑證寫進提示詞。

## 晨報與可選觀察

晨報可包含六項：已接收階段與基線、實際採用程式碼的工作區、未完技術項與條件、有意義的材料與備份決定、執行觀察及涵蓋範圍、下一步與使用者操作。只建議有意義的備份，重用已驗證副本與既有保留決定。晨報描述出報時狀態，後續完成另報。

報告的產生與送達由 AI 和宿主完成。AGCT 沒有提供持久化的每日一次出報器、原生對話採集器或自動提醒計數器。提醒次數等策略應依專案明確設定，沉默不產生授權。

需要觀察者時，可另建獲准的唯讀任務，使用以下說明：

```text
唯讀觀察本專案的 AGCT status、agenda 與 doctor 結果。比較最新治理完成結果的明確範圍、目前未完操作與執行證據。不要接收、採用、恢復、安裝、改任務狀態、啟動其他代理或批准治理寫入者。安裝成功不能證明所有宿主程序已重新載入。發現新增不一致或需要行動的變化時，說明具體物件與證據；歷史保留狀態不變時不重複通知。觀察不可用是涵蓋缺口，不是失敗或成功的證明。
```

## 驗證真正使用的接入方式

核對儲存後的對話與專案、週期、時區、模型設定、工具與執行環境存取能力。CLI 成功不能證明 MCP 已接通或原生定時已成功觸發。先驗證手動提示詞，再檢查首次定時結果；存取本機檔案的任務需要電腦與桌面應用程式可用。參見[官方定時任務文件](https://learn.chatgpt.com/docs/automations?surface=app)。

AGCT 限制本批接收工作數量，並支援已實作操作的中斷接續；它不強制終止 AI 對話、任意外部指令，也沒有多電腦協調鎖。需要停止時使用宿主控制，保留交易記錄。更多邊界見[維護與安全接續](governance-maintenance.md)。
