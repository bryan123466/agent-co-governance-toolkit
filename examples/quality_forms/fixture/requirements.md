# Fictional quality-form requirements

Build a small, file-based quality record set for a fictional workshop.

- Record inspection counts and cosmetic defect categories.
- Keep reviewed and closed states separate.
- Link corrective actions to inspections and record effectiveness checks.
- Summaries must distinguish observations, proposed action, verified action, and pending decisions.
- Use only the invented identifiers included here. Do not add real names or customer data.

This is a software-workflow fixture, not a certified quality system or a compliance template.

# 虚构品质表单需求

为虚构车间构建一组文件式品质记录：记录检查数量与外观缺陷类别，区分已复核与已关闭，将纠正措施关联到检查并保留有效性验证。汇总中区分观察、拟议措施、已验证措施和待定决定。

仅使用虚构标识，不加入真实人员或客户资料。这是软件工作流资料，不是经过认证的品质体系或合规模板。
