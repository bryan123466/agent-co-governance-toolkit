# Review checklist / 复核清单

- Confirm the inspection identifier exists. / 确认检查编号存在。
- Check counts and defect category against the recorded observation. / 核对数量和缺陷类别。
- Keep a proposed action distinct from verified effectiveness. / 区分拟议措施与有效性已验证。
- Record a pending decision when evidence is absent. / 证据缺失时记录待定决定。
- A file commit is not review approval. / 文件提交不等于复核批准。
