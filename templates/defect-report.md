- Toolkit version / 工具版本:
- OS and Python/Git versions / 系统与 Python、Git 版本:
- Interface: CLI, MCP, or Codex model-assisted / 接口:
- Expected behavior / 预期行为:
- Actual behavior and error code / 实际行为与错误编号:
- Small reproduction steps / 最小复现步骤:
- Sanitized request JSON / 脱敏请求:
- Sanitized result envelope / 脱敏结果:
- Did any Git effect occur before the error? / 出错前是否已有 Git 效果:
- Repeat behavior, without blind retries / 在核对效果后再次运行的情况:
- Data loss observed, or no loss verified / 是否有内容丢失，如何核对:
- Scope not tested / 尚未验证范围:
